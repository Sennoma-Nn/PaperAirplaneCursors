## Build and Install

- Required: <strong>inkscape, xcursorgen, posix shell</strong>

- Build
    ```shell
    git clone https://github.com/Sennoma-Nn/PaperAirplaneCursors.git
    cd PaperAirplaneCursors
    sh ./script/build.sh

    ```

- Install from Build
    ```shell
    mkdir -p ~/.icons && cp -r ./build ~/.icons/PaperAirplaneCursors

    ```
